# cleyxcode // Portfolio

Personal portfolio website for Bredcly F Tuhuleruw, also known as cleyxcode. The site showcases full-stack web development, mobile applications, school information systems, organization platforms, IoT projects, machine learning, Unity, and augmented-reality work.

## Built with

- React and Vite
- Tailwind CSS
- JavaScript and TypeScript ecosystem
- Responsive layouts with dark mode support
- Groq-powered portfolio chatbot

## Highlights

- Project showcase with responsive desktop and mobile mockups
- About, experience, education, tech stack, certificates, and contact sections
- Interactive project cards with live project and source-code links
- Responsive profile presentation and downloadable CV

## Development

```bash
npm install
npm run dev
```

Create a local `.env.local` file if the chatbot is enabled:

```env
VITE_GROQ_API_KEY=your_groq_api_key
```

Build for production:

```bash
npm run build
```
